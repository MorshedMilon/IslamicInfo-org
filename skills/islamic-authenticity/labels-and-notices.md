## Mandatory Notice: Weak Hadith (DA'IF)

Append this in full after any da'if citation:

```
⚠️ WEAK HADITH NOTICE
─────────────────────────────────────────────────
This narration has been graded DA'IF (weak) by [Scholar Name].

A weak hadith MUST NOT be used as evidence for religious rulings (ahkam).
Some scholars permit weak hadith for virtuous deeds (fada'il al-a'mal)
under strict scholarly conditions. Do not act on this narration without
first consulting a qualified Islamic scholar ('alim).
─────────────────────────────────────────────────
```

This narration has been graded DA'IF JIDDAN (very weak) by [Scholar Name].

## Mandatory Notice: Fabricated Narration (MAWDU')

```
🚫 FABRICATED NARRATION — NOT A HADITH
─────────────────────────────────────────────────
This narration has been classified as MAWDU' (fabricated) by [Scholar(s)].

It is NOT an authentic hadith and must NOT be attributed to the Prophet ﷺ.
Spreading fabricated narrations is a serious matter in Islamic scholarship.

Classified by  : [Scholar name(s)]
Reference      : [Book or source of the classification]
─────────────────────────────────────────────────
```
